# 👋 Welcome to vCore Framework

## Apa itu vCore?

vCore adalah framework FiveM modern yang dibangun dengan arsitektur modular dan clean code. Dirancang untuk developer yang menginginkan framework yang powerful, mudah dikustomisasi, dan performa tinggi.

{% hint style="success" %}
**vCore Framework v1.0.0** - Production Ready!
{% endhint %}
